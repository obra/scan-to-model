Use this skill to continue an evidence based architectural reconstruction. The working unit is a useful model outcome: a room boundary with its openings, a connected stair/landing, or a coherent exterior section. Source inspection and tools serve that outcome. Preserve accepted geometry, immutable evidence and explicit uncertainty.

## Continue from the checkpoint

Read the current handoff and active package, then follow their links to the accepted geometry and source dispositions needed for that package. Confirm the current model identity and execution restrictions. Reuse settled source identities, coordinate conventions, measurements and rejected attempts within their recorded scope. Do not restart intake, coverage accounting or the whole task register on every increment.

Choose the largest supported missing boundary or connection in the current priority phase. Where the project prioritizes house geometry, work through levels, enclosure, walls, floors, ceilings, stairs and openings before fixtures or cosmetic details. A blocked structural region sends work to another structural region. Keep one geometry increment active so building, review and acceptance can finish together.

## Build an outcome

1. State what will visibly change, its existing source/placement authority, and what would make the increment complete. Inspect the current geometry at the affected interfaces before creating adjacent surfaces. Group related faces into the same implementation and review.
2. Open the relevant supplied photos or native frames to decide the remaining topology or boundary. Measure only a named physical fact that changes the proposed geometry. Use accepted dimensions and qualified placement where they already apply; an unknown hidden depth need not block a supported visible surface.
3. Once supported geometry can be specified, build the candidate. Keep unsupported contacts, hidden continuations and uncertain dimensions explicit. Do not turn an appearance observation or seed coordinate convention into metric acceptance.
4. Check the changed geometry, its adjoining accepted objects and source appearance; compare inventories to preserve unrelated content. Reopen the saved candidate before promotion. Apply the scoped review in [blender-review.md](../../references/blender-review.md).
5. Record the delivered outcome and remaining physical limits once in the existing project records, update affected drawings at the agreed delivery boundary, and continue to the next structural outcome. A source packet or offline draft is preparation until integrated and reviewed.

If a bounded source check cannot answer its named question, preserve that result and move on. Reopen settled work only for a specific new source, owner correction, demonstrated conflict in current geometry, or changed required use; state which decision this could change. A new worker, stale summary, different packet name or opportunity for tighter precision is not new evidence. See [work-packets.md](../../references/work-packets.md) for worker roles and stopping conditions.

When Blender or another required runtime is paused, prepare a coherent implementation batch using retained evidence. Stop that batch when only prohibited native integration/review remains. Report it as prepared and retain the exact resumption action; do not replace the blocked modeling lane with repeated adjacent investigations or bookkeeping. Continue an independent authorized outcome only when it has its own useful deliverable.

## Route only the needed work

Use [evidence-workflow.md](../../references/evidence-workflow.md) for provenance and retention boundaries and [project-records.md](../../references/project-records.md) for the existing record shapes. Consult [goals.md](../../references/goals.md) when setting or revising the project outcome.

- `scan-ingest`: new archives and source availability.
- `source-observe`: visible construction and photograph-first inventories, independent of unsettled placement.
- `street-view-reference`: supplemental exterior imagery.
- `depth-inspect`: a specific native-depth or surface measurement question.
- `scan-register`: a required rigid alignment and independent validation.
- `blender-reconstruct`: candidate construction, preservation review and promotion.

Delegate mechanics when authorized; root owns physical interpretation, work selection and acceptance. Improve a tool when a demonstrated defect or repeated operation blocks the current build, then return to that build. Keep private evidence outside the plugin, publishing authority in the project, and current finishes separate from historical construction and observed services. Do not add approval gates or depend on Superpowers.
