---
name: blender-reconstruct
description: Build and review evidence tagged Blender architectural candidates while preserving unrelated scene content.
---

Use for Blender candidate edits, preservation review, and promotion. Edit a candidate first; retain architecture, movable contents, current finishes, historical construction, and observed services as separate categories. Reuse doors/windows only when trim and dimensions agree. Tag objects with source and uncertainty metadata. Services describe observed routes only; never invent hidden continuation.

Keep source traces separate from manufactured component geometry. When photographs or an explicit owner correction establish rectangular panels, fit rectangles in a common component frame instead of carrying projected skew into the part. Preserve original controls, record the constraint's evidence and fit residuals, and retain dimensional uncertainty. Check dependent openings and profiles in the saved native geometry as well as the diagram.

Render source matched views plus top/section views, reopen the saved file, and inspect the result before promotion. Run `blender_review.py` on input and candidate inventories; it must never save or modify the input scene. Read [blender-review.md](../../references/blender-review.md) and [evidence-workflow.md](../../references/evidence-workflow.md).
