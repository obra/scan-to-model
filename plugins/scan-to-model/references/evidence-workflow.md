# Evidence workflow

Keep an immutable source ledger with SHA256 hashes. Every derived point, plane, transform, and object records source archive/capture, frame or photo, native pixel/coordinate where available, variant, and provenance class. The coverage atlas tracks rooms, surfaces, and connections as supported, partial, conflicting, inaccessible, or unobserved. Shot lists point to actual source photos; retire requests once evidence exists. A ruler is optional independent control.

Depth availability, local repeatability, and absolute accuracy are separate findings. Glass may return background; furniture may occlude fixed surfaces. Compare dated open-wall evidence locally with current scans before carrying service routes forward. Current scans normally determine current finishes.

Use rigid shared surfaces and distributed landmarks. Keep withheld check sets independent. Preserve rejected samples and all point residuals. Regularize with planes or right angles only when evidence supports it; never deform rooms to hide drift. Unknown boundaries remain unknown.

In Blender, separate architecture, contents, current, historical, and services. Preserve unrelated objects and materials. Review source matched and top/section renders, reopen saved files, then promote only changes supported by evidence.
